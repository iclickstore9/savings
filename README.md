# กระปุกออม 🐷

เว็บแอปบันทึกเงินออมแยกตามเป้าหมาย (สร้างบ้าน, จ่ายประกัน ฯลฯ) ออกแบบสำหรับมือถือ
ใช้ได้ทั้งออนไลน์และออฟไลน์ ข้อมูลเก็บใน **เครื่องของคุณเท่านั้น** (localStorage) ไม่มีการส่งขึ้นเซิร์ฟเวอร์

## ฟีเจอร์
- สร้างเป้าหมายได้หลายอัน 3 ประเภท: **ออมเงิน** (เป้า + ออมประจำเดือนละ + โน้ต), **ลงทุน** (ต้นทุน vs มูลค่าปัจจุบัน → กำไร/ขาดทุน), **หนี้/ผ่อน** (ค่างวด × จำนวนงวด → คงเหลือ, เหลือกี่งวด, งวดสุดท้ายประมาณเมื่อไร, ปุ่มจ่ายงวด)
- บันทึกฝาก/ถอนทีละรายการ พร้อมวันที่และโน้ต (แตะรายการเพื่อแก้ไข/ลบ)
- ดูยอดรวม, % ความคืบหน้า, ประวัติแยกรายเดือน
- **คาดการณ์** (ในหน้าเป้าหมาย): ฝากเท่านี้ถึงเป้าเมื่อไร / ต้องฝากเดือนละเท่าไร — รองรับยอดฝากแบบขั้นบันได, เงินก้อนรายปี (โบนัส) และดอกเบี้ย — จำค่าที่กรอกไว้ให้
- **รายรับรายจ่าย** (แท็บล่าง): บันทึกรายรับ/รายจ่ายแยกหมวด (หมวดตั้งต้น + เพิ่มเองได้), สรุปรายเดือน รับ/จ่าย/คงเหลือ, กราฟรายจ่ายตามหมวด (แตะเพื่อกรอง), เทียบเดือนก่อน
- **รายการประจำ**: รายรับ/รายจ่ายประจำเดือน ขึ้นให้กดยืนยันทุกเดือน แก้ยอดหรือข้ามเดือนได้
- **วางแผนรายเดือน**: คำนวณคร่าวๆ จากรายการประจำ (ลองแก้ยอด/ติ๊กออกได้โดยไม่กระทบของจริง) + รับอื่นๆ/จ่ายอื่นๆ → เหลือใช้จ่ายต่อเดือนและต่อวัน
- **ออมเงินที่เหลือ**: โอนเงินเหลือของเดือนเข้าเป้าออม (ผูกกันสองฝั่ง แก้/ลบที่ไหนก็ตามกัน)
- **ธีม** (เมนู ⋮): โหมดตามมือถือ/สว่าง/มืด + สีหลัก 6 สี — จำแยกตามเครื่อง
- **ซิงก์ Firebase** (ไม่บังคับ): ล็อกอิน Google แล้วข้อมูลซิงก์ระหว่างเครื่องแบบ real-time ใช้ออฟไลน์ได้
- Export / Import ไฟล์สำรอง (.json) — เมนู ⋮ มุมขวาบน

## เอาขึ้น GitHub Pages (ฟรี)
1. สร้าง repo ใหม่ที่ https://github.com/new (เช่นชื่อ `savings`)
   - GitHub Pages แบบฟรีต้องเป็น **Public** repo — ไม่เป็นไร เพราะในโค้ดไม่มีข้อมูลเงินของคุณ
2. อัปโหลดไฟล์ทั้งหมดในโฟลเดอร์นี้ (กด *Add file → Upload files* แล้วลากไฟล์ + โฟลเดอร์ `icons` และ `fonts` ไปวาง)
3. ไปที่ **Settings → Pages** → Source: *Deploy from a branch* → Branch: `main` / `(root)` → Save
4. รอ 1–2 นาที จะได้ลิงก์ `https://<ชื่อผู้ใช้>.github.io/savings/`

## ติดตั้งบนมือถือ
- **iPhone (Safari):** เปิดลิงก์ → ปุ่มแชร์ → *เพิ่มไปยังหน้าจอโฮม*
- **Android (Chrome):** เปิดลิงก์ → เมนู ⋮ → *ติดตั้งแอป* / *เพิ่มลงในหน้าจอหลัก*

> ⚠️ ข้อมูลอยู่ในมือถือเครื่องนั้น ถ้าลบแอป/ล้างข้อมูลเบราว์เซอร์ ข้อมูลจะหาย — Export สำรองเป็นระยะ

## อัปเดตเวอร์ชัน
เมื่อแก้ไฟล์แล้วอัปโหลดใหม่ ให้เปลี่ยนเลข `CACHE` ใน `sw.js` (เช่น `kapook-om-v2`)
เพื่อให้มือถือโหลดไฟล์ใหม่ (อาจต้องเปิดแอป 2 ครั้ง)

## ตั้งค่าซิงก์ Firebase (ไม่บังคับ)
1. Firebase console → เลือกโปรเจกต์ → ⚙️ Project settings → Your apps → เพิ่ม Web app (`</>`) → คัดลอก `firebaseConfig` ใส่ใน `firebase-config.js`
2. **Authentication** → Sign-in method → เปิด **Google**
3. **Authentication** → Settings → Authorized domains → เพิ่ม `<ชื่อผู้ใช้>.github.io`
4. **Firestore Database** → Create database (Production mode, region `asia-southeast1`)
5. Firestore → **Rules** → วางเนื้อหาจากไฟล์ `firestore.rules` → Publish

ข้อมูลเก็บที่ `users/{uid}/` → `goals`, `entries`, `txns`, `categories`, `recurring`, `plans` — ถ้า `firebase-config.js` ว่าง แอปจะใช้แบบเก็บในเครื่องอย่างเดียว
